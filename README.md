# Skillnexis Python Projects

This repository contains the Python projects developed during my **Skillnexis internship**. The projects focus on learning Python programming fundamentals and applying them through practical programs.

## 📁 Projects

### Project 1 – Simple ATM Simulator

A basic ATM simulation program developed using Python.

**Features:**

* 🔐 PIN-based user login
* 💰 Check account balance
* 💵 Deposit money
* 💸 Withdraw money
* 🚪 Exit the ATM system

**Python concepts used:**

* Variables and data types
* Input and output
* If-else conditions
* While loops
* Functions
* Basic modular programming

## 🛠️ Technologies Used

* **Python**
* **Visual Studio Code**
* **Git & GitHub**

## ▶️ How to Run

1. Install Python on your computer.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Navigate to the project folder.
6. Run the Python file:

```bash
python atm_simulator.py
```
